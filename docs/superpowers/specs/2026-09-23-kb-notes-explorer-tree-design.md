# 设计：速记文件夹树 — 资源管理器布局（去掉全部/未分类）

- 日期：2026-09-23
- 状态：对话已确认（demo v3）
- 分支：`feature/kb-notes-structure`（基于已实现结构段）
- 关联：
  - `docs/superpowers/specs/2026-09-23-kb-notes-structure-design.md`（数据层 / 导入 / 删除升迁仍有效）
  - 交互原型：`.superpowers/brainstorm/*/content/explorer-layout-v3.html`

## 1. 目标与范围

把速记左侧从「虚拟根节点（全部笔记 / 未分类）+ 下方夹内列表」改为**单栏资源管理器树**：真实文件夹优先，夹内笔记缩进挂在文件夹下；无文件夹的笔记排在所有文件夹之后；右侧只承担编辑器。

### 1.1 本段交付

- UI：去掉「全部笔记」「未分类」虚拟节点
- UI：去掉左侧树下方单独的「夹内笔记卡片列表」区（与树重复）
- 树交互：单击展开/收起；双击名称行内重命名；FolderPlus 顶部行内新建；拖拽文件夹排序
- 行内编辑：名称输入 + 排序数字（默认 = 当前根级文件夹数 + 1，带增减）+ √ 保存；不弹窗、不位移
- 新建笔记：未指定文件夹 → 顶级（`folder_id = NULL`）；创建流程提供可选「文件夹」文本字段——空 = 顶级；已有同名根级夹 = 放入；不存在 = 先 `create_folder` 再创建笔记放入
- 数据语义：`folder_id IS NULL` 仍表示顶级笔记（产品文案改称「顶级」，不再展示「未分类」入口）

### 1.2 本段不做

- 笔记行拖入文件夹（仍可用现有右键「移动到…」；HTML5 DnD 笔记归档本结构段已放弃）
- 改删除升迁 / 导入 / `source_path` 语义
- 修复 `refreshNotes`+`list_meta` 冲正文（另案，不阻塞本 UI）

## 2. 布局（已批准）

```
┌─ 速记 ──────────────┬─ 编辑器 ─────────────┐
│ 文件夹    [Folder+] │                      │
│ ▾ 工作            2 │   选择或新建笔记     │
│     会议纪要        │   （点树内笔记打开） │
│     周报模板        │                      │
│ ▸ 学习            1 │                      │
│ 临时想法            │                      │
│ 购物清单            │                      │
└─────────────────────┴──────────────────────┘
```

规则：

1. **单栏树**：文件夹与笔记在同一滚动容器；不分区、无「文档区」分隔条。
2. **排序**：先按 `sort_order` 列出全部根级文件夹；每个展开文件夹下紧跟其直属笔记；所有根级文件夹之后再列 `folder_id IS NULL` 的笔记。
3. **展开**：只改变树缩进子节点；**不**在树下方再渲染夹内列表。
4. **选中文件夹**：可高亮；右侧不自动铺夹内笔记列表（点笔记才打开编辑器）。
5. **筛选**：不再有「全部 / 未分类」过滤键；默认树即全貌。打开某笔记时仍展开其父链。

## 3. 交互细则

### 3.1 文件夹

| 操作 | 行为 |
|------|------|
| 单击文件夹行（名称或行） | 展开/收起；可选中该夹 |
| 双击文件夹名称 | 该行变为行内编辑（名称 + 排序 + √） |
| 按住拖拽文件夹行 | 仅根级文件夹之间重排；写回 `sort_order`（1…n） |
| 点树头 FolderPlus | 在树**顶部**插入一行编辑态（自动聚焦）；默认排序 = 当前根级文件夹数量 + 1 |
| 点 √ 或 Enter | 校验非空、同级重名；新建或保存重命名；Esc 取消 |
| 删除 / 移到父级 | 沿用现有右键菜单 + ConfirmDialog（升迁删除语义不变） |

行内编辑控件（相对现有 UI 仅新增）：

- 文本输入（文件夹名）
- 排序数字框 + ▲▼ 步进（默认见上）
- √ 保存按钮（可用 lucide `Check`）

视觉：尽量沿用现有紫灰、`Folder`/`FolderPlus`/`Chevron*`；不改标题栏导入/新建笔记图标。

### 3.2 笔记

| 操作 | 行为 |
|------|------|
| 单击树内笔记 | 打开编辑器（右侧） |
| 右键 | 现有「移到未分类 / 移动到文件夹…」（文案可将「未分类」改为「移到顶级」） |
| 标题栏「＋」/ 空态「新建笔记」 | 打开轻量创建条或沿用现流程：默认 `folder_id = NULL`；若当前树选中真实文件夹则默认放入该夹；另提供「文件夹」文本框（可空）：已有根级同名 → 用其 id；否则创建根级夹再放入 |
| 右键 | 现有移动菜单；「移到未分类」文案改为「移到顶级」 |

### 3.3 与旧虚拟节点的对照

| 旧 | 新 |
|----|----|
| 「全部笔记」筛选 | 删除；树本身展示全部 |
| 「未分类」筛选 | 删除；顶级笔记出现在树末尾 |
| 下方夹内列表 | 删除；展开即见 |

## 4. 实现要点（相对现码）

- **布局**：`NoteList` 左侧改为**单一 explorer 树**（文件夹 + 笔记节点）；删除树下方独立的笔记卡片列表（原 `nl-list` / 选中夹后的夹内列表）。右侧整栏仅编辑器（`NoteEditor` / 空态「选择或新建笔记」）——与 demo v3 一致。
- `NoteFolderTree` / 树数据：去掉 `kind: 'all' | 'uncategorized'`；渲染顺序 = 根级文件夹（按 `sort_order`）→ 展开时插直属笔记 → 末尾 `folder_id == null` 的顶级笔记。
- 新建/重命名文件夹：行内编辑替代 `window.prompt`（FolderPlus 与双击两条路径）。
- `sort_order`：拖拽与行内数字写同一字段；若缺批量重排则加 `reorder_note_folders(ids: number[])`。
- 文案：「未分类」→「顶级」（路径条、删除确认、右键菜单）。
- 标签筛选：若仍需要，放在树头或编辑器侧，**不**恢复「全部/未分类」虚拟文件夹行。
